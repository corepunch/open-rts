# Zod and Stargus implementation coverage

Source inventory at open-rts `efa8ee2`, Zod `5ccb43ab76ee08c9f624906fb465dc3ba76a7a35`, and Stargus `2a4d54604949e4772f6638a8412c8ebd62444044`. This is a bounded module-level comparison, not a claim of retail or reference parity. The source groups below cover the reference gameplay and AI entry points identified in these trees; an **open** row identifies concrete remaining work, and **partial** means only the cited behavior is present. A reference's policy, constants, incomplete code, or TODO is not evidence of the original game. Existing verified native findings take priority over conflicting remake policies.

After the StarCraft projectile and order-queue changes, the headless AI soak passed 30 simulated
minutes for each of the three races and a 15-minute duel. Protoss made 114
purchases and 7 waves, Zerg 201 and 17, Terran 164 and 7; the run exercised
advanced units, level-three research, expansions, bunkers, siege, storm, holds
and retreats. The native-data C weapon generator also reproduced all 100
weapon rows byte for byte. All seven binaries built, StarCraft/Dark Colony/
Warcraft II headless smokes passed, and the shared network suite passed all
18 cases with loopback access. The soak does not establish identical Stargus
AI policies.

The concrete unported Zod gameplay policies identified in this audit are the
move-order opportunistic pickup detour (`CheckOpportunisticGrab`), run stamina
and random start (`ProcessRunStamina` / `AttemptStartRun`), and displacement
evasion (`DodgeMissile`). These are working fork behaviors, not a claim that
retail lacks related mechanics. They remain unadopted because the traced
native movement and projectile reaction paths do not establish those policies;
the exact native movement modifiers and pickup triggers remain open. Zod's
full set of waypoint types is also not reproduced by the eight-point rally
route. Presentation, replay/service compatibility, and matching every
reference AI policy are separate from these concrete logic gaps.
